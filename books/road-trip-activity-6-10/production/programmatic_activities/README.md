# BOOK_001 — Programmatic Activity Engine

This folder contains a deterministic generator for the 48 activities that should be generated by code rather than image generation.

## Scope
- Pages 15–30: 16 mazes (6×6, 8×8 and 10×10).
- Pages 31–42: 12 dot-to-dot activities (30 or 50 numbered points).
- Pages 43–54: 12 word searches (10×10; 8 or 10 words).
- Pages 73–80: 8 travel games (alphabet, I Spy, counting, bingo).

Coloring pages, spot-the-difference artwork, creative drawing pages and front matter are outside this generator.

## Run
From this directory, run:
    python -m unittest -v
    python generate_activities.py --output-dir generated_activities

The output consists of print-sized SVG pages, machine-readable answer keys and a validation report.

## Quality model
- Mazes use seeded randomized depth-first search; a breadth-first search solution is stored in the answer key.
- Dot-to-dot pages contain exactly the requested number of numbered points; coordinates are stored in the answer key.
- Word-search grids are generated from their word lists; placements and directions are stored alongside the exact grid.
- Counting games store their exact counts; bingo pages store their square inventories.
- The generator is deterministic for a fixed seed.

## Important status
GENERATED_NEEDS_VISUAL_REVIEW means algorithmic checks passed. It does not mean pages are approved for KDP. All SVGs still require visual inspection, English proofreading, print-size review and final PDF/KDP preview checks. This engine does not alter the official 80-page manifest and does not publish to Amazon.
